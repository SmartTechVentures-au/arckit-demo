## Summary

Rationalise six web properties (1× self-managed Magento B2B + 5× Shopify B2C)
to ≤ 3 B2C storefronts plus 1 B2B trade portal on SaaS/PaaS. Single product
source, hub-sourced availability (zero web oversell), CRM-authenticated
accounts, click-and-collect with Project 004, WCAG 2.2 AA, and retirement of
self-managed commerce infrastructure.
